🐞 I Want to Fix a Bug

**Awesome!**

COW exists so improvements happen in the original project instead of another fork, with as little work as possible.


## How it works

1. Fork the repository.
2. Create a branch.
3. Make your changes.
4. Open a Pull Request.
5. Another COW member reviews it.
6. After approval, the PR is merged.
7. The workshop is updated automatically.

No need to create "Better XYZ Mod Patch Patch" just because you fixed one bug.
