# 🎮 I'm a Player

**Great!**

Players are the most important part of every community project. You don't need to write code to help COW.

## You can help by

- Reporting bugs.
- Suggesting new features.
- Explaining how to reproduce problems.
- Helping other players.
- Encouraging your favorite mod authors to join COW.

Every issue makes the mod better.


## Report a Bug

If you found a problem, please create an issue in the project's GitHub repository.

Try to include:

- game version
- mod version
- steps to reproduce
- screenshots or logs (if available)

Good bug reports save everyone time.


## Ask Your Favorite Mod Author

Many authors don't know COW exists yet.

If you enjoy a mod that isn't part of COW, let the author know about the initiative.

One friendly message can keep a great mod alive for years.

Please don't spam or pressure authors. COW is entirely voluntary.
