# COW Assets

If you want to use these assets to announce your COW mod, go ahead!

In the SVG files, you can change **`style="color: #991111"`** (around line 7) to change the seal color.

In the files with a background, you can also change the following snippet to change the background color:

```css
.paper-fill {
    fill: #123456;     /* e.g. "red", "green", "none" or hex value */
}
```

The banner was made with [WiseStamp](https://www.wisestamp.com/banner-maker/)
